# Security

Report a suspected Citevia vulnerability privately to eyal@citevia.io and gaby@citevia.io. Include affected functionality, a minimal reproduction and potential impact. Do not include live credentials, personal customer data or destructive proof-of-concept actions in public issues.

The production application and its current default branch are the maintained versions. Security fixes must preserve tenant authorization, paid-call uncertainty handling and approved publication snapshots. Run the checks in [the assurance plan](docs/SECURITY_ASSURANCE.md) and document unresolved risks before release.

Security and operations contacts: eyal@citevia.io, gaby@citevia.io, info@citevia.io. The [assurance inventory](docs/SECURITY_REVIEW_INVENTORY.md) and [incident/recovery procedures](docs/SECURITY_ASSURANCE.md) distinguish implemented controls from acceptance work. No certification or response-time commitment is implied by this document.
